# 脉络详情页 AI 分析重设计

**日期：** 2026-04-21  
**状态：** ✅ 设计确认

---

## 一、目标

在脉络详情页新增「一些碎片」和「此刻这里」两个 AI 生成段落，由用户手动点击触发分析，结果持久化存 DB。「走过的路」（条目时间线）保持不变。

---

## 二、页面结构

```
┌─────────────────────────────────────┐
│  脉络名称                  [已确认] │
│  3个月 · 12条记录 · 最近更新 4月18日│
├─────────────────────────────────────┤
│  一些碎片                           │
│                                     │
│  「……」              4月10日        │
│  「……」              2月14日        │
│  「……」              3月22日        │
├─────────────────────────────────────┤
│  此刻这里                           │
│                                     │
│  目前这个主题似乎正在从……           │
├─────────────────────────────────────┤
│  走过的路                           │
│                                     │
│  4月18日   在咖啡馆被旁边的人影响…  │
│  4月10日   地铁上遇到……             │
│  （共12条）                         │
├─────────────────────────────────────┤
│            [重新分析]               │
└─────────────────────────────────────┘
```

三个段落职责不重叠：
- **一些碎片**：用户自己的声音，AI 只负责挑选
- **此刻这里**：AI 对这条脉络「目前在哪里」的 3–5 句读取
- **走过的路**：原始条目时间线，用户自己翻看

---

## 三、AI 生成规则

### 触发时机

**手动触发**：用户点击「重新分析」（或首次进入时的「开始分析」）。不自动触发，不与条目新增绑定。

### 一次调用完成两件事

一次 API 调用同时生成碎片和此刻，输出结构化 JSON：

```json
{
  "fragments": [
    { "quote": "原句", "date": "YYYY/MM/DD" },
    ...
  ],
  "current_state": "3–5句话描述此刻位置。"
}
```

### 入参

- `{{thread_name}}`
- `{{entry_count}}`、`{{date_range}}`
- `{{entries_with_dates_and_content}}`：每条完整的用户原文 + 日期（不用摘要，碎片需要引用原句）

每条格式：
```
[YYYY/MM/DD]
{content}
```

### Prompt 全文

````
你会读到用户追踪「{{thread_name}}」这条脉络的所有记录（{{entry_count}} 条，{{date_range}}）。

完成以下两件事，输出一个 JSON，不要解释：

────────────────────────────────────
【任务一：挑碎片】

从记录里挑 2–5 句原句，标准：
- 每句里有一个具体的发现、悖论、或行为转变
- 句子之间不能说同一件事
- 用原文，不改写，不截断到语义不完整

────────────────────────────────────
【任务二：写此刻这里】

读完所有记录后，写 3–5 句话描述这条脉络「目前在哪里」——
不是它经历了什么，而是此刻这个主题的状态和方向。

必须做到：
- 用试探性语言：「似乎」「好像」「目前」「可能」「也许」
- 用用户自己写过的词或场景
- 描述变化和方向，不描述固化特质

绝对不能：
- 「你是一个……的人」「你总是……」「你一直……」
- 「这说明……」「这意味着……」「由此可见……」
- 「建议你……」「你应该……」「你可以试试……」
- 超过 5 句
- 通用句（「你在成长」「你承受了很多」）

如果记录只有 1–2 条：不要强行描述轨迹，只描述此刻看到的状态。
如果记录跨度很长：聚焦最近几条，描述当下方向，不试图概括全部历史。

────────────────────────────────────
【输出格式】

{
  "fragments": [
    { "quote": "原句", "date": "YYYY/MM/DD" },
    { "quote": "原句", "date": "YYYY/MM/DD" }
  ],
  "current_state": "3–5句话，此刻这里。"
}

以下是记录：
{{entries_with_dates_and_content}}
````

## 四、数据存储

### DB 变更

`threads` 表新增三列（Supabase SQL Editor 手动执行）：

```sql
ALTER TABLE threads
  ADD COLUMN IF NOT EXISTS fragments jsonb,
  ADD COLUMN IF NOT EXISTS current_state text,
  ADD COLUMN IF NOT EXISTS analysis_generated_at timestamptz;
```

### 初始状态

- `fragments IS NULL`：「一些碎片」和「此刻这里」显示占位态 + 「开始分析」按钮
- 分析完成后存入三列，显示结果 + 「重新分析」按钮

## 六、成功标准

1. 进入未分析的脉络详情，看到「开始分析」入口，两个 AI 段显示占位
2. 点击后 AI 调用，完成后「一些碎片」显示 2–5 句原句带日期
3. 「此刻这里」显示 3–5 句，有试探性语言，无建议/诊断/标签
4. 「走过的路」条目列表正常显示，不受影响
5. 再点「重新分析」，内容更新，时间戳刷新
6. 碎片引用的句子能在原始条目中找到原文（不是 AI 编造）
