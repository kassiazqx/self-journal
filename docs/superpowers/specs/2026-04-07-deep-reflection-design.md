# 深度复盘功能 · 设计文档

**日期**：2026-04-07  
**状态**：已确认，待实现

---

## 背景与目标

当前的"复盘"路径是写完日记 → 情绪标注 → 强制进入 AI 对话。AI 每次都主导提问，节奏慢、不可控，用户体验像"被审讯"而不是"自我梳理"。

本次重设计目标：
1. 让深度复盘变成**可选**的，而不是默认流程
2. 用**结构化问题卡片**代替 AI 提问，用户主动梳理
3. AI 退为**随时可唤起的辅助工具**，不主导节奏
4. 所有内容自动保存，退出即完成，无需手动点"保存"

---

## 整体流程

```
Page 1 写日记
  → 点【下一步】→ 内容立即写入数据库

Page 2 情绪标注（TaggingPage）
  → 选情绪 / 状态评分（改动已标注的字段随时 fire-and-forget 同步）
  → 底部两个按钮（左小右大）：
    [深度复盘]          [完成]
  → 点【完成】→ 直接回记录列表
  → 点【深度复盘】→ 进入新页面 ReflectionPage

ReflectionPage（新增）
  → 4张问题卡片，左右滑动切换
  → 每张卡片：字段标签 + 问题 + 输入框 + "↻ 换一个问题"
  → 右下角小圆 AI 按钮（✦），点击唤起全局 AI 对话
  → 顶部右"关闭" → 直接回记录列表，已填内容全部已自动保存
```

---

## 情绪标注页改动（TaggingPage）

仅在底部操作区做最小改动：

**改前**：一个「完成」按钮  
**改后**：两个并排按钮

```
[深度复盘]      [    完成    ]
 左侧偏小         右侧更宽
 灰色边框         amber 填充
```

- 「完成」：保持现有行为，点击后跳回记录列表
- 「深度复盘」：进入 ReflectionPage，传入当前 entry 对象

## ReflectionPage（新增页面）

### 顶栏

```
← 1/4      深度复盘      关闭
```

- 左：当前进度（"‹ 2/4"），点击可返回上一张卡片
- 中：页面标题
- 右："关闭" → fire-and-forget 保存当前输入 → 回记录列表

### 卡片区（全屏，左右滑动）

每张卡片结构：

```
┌──────────────────────────────┐
│  [字段标签]                   │
│  问题文字                     │
│                               │
│  ┌────────────────────────┐  │
│  │ 文本输入框（多行）       │  │
│  └────────────────────────┘  │
│  ↻ 换一个问题                 │
└──────────────────────────────┘
                              ✦
● ○ ○ ○   （进度点，当前高亮）
```

- **文本输入框**：onBlur 时 fire-and-forget 保存到对应字段
- **换一个问题**：从同一字段的问题库里随机换一个，不改变字段，不清空已输入内容
- **✦ 按钮**：右下角小圆，点击唤起 AI 对话（见下方）
- **左右滑动**：切换卡片，不强制必须填完才能滑

### 默认 4 张卡片（字段 → 问题组）

| 卡片 | 字段 | 默认问题 | 可换问题池 |
|---|---|---|---|
| 1 | `current_thought` | 当时你脑子里第一个念头是什么？ | 当下你心里第一个念头是什么？/ 那个时刻最先冒出来的词是什么？ |
| 2 | `core_needs` | 在这件事上，你真正需要的是什么？ | 什么对你来说最重要？/ 这件事触动了你的什么？ |
| 3 | `body_sensations` | 这个感觉在身体哪个部位？ | 是什么质地？紧绷、沉重、还是别的？/ 现在坐着，身体哪里是紧的？|
| 4 | `reflection_insight` | 聊到现在，有什么是刚才才意识到的吗？ | 有没有哪句话，说出来之后觉得"对，就是这个"？/ 如果给今天的自己说一句话，会是什么？ |

**第 3 张（body_sensations）动态显示规则**：
- 情绪列表中包含以下任一词时显示：焦虑、崩溃、难受、委屈、绝望、压抑、愤怒、恐惧
- 否则第 3 张替换为 `handling_rating`（处理方式）：回头看，你觉得自己当时处理方式怎么样？

### AI 入口（✦ 按钮）

- 每张卡片右下角固定位置，小圆图标，amber 边框，低调不抢眼
- 点击后：全屏覆盖打开 AI 对话（复用现有 `AIConversation` 组件）
- AI 收到的上下文 = `getInitialUserMessage(entry)` 的内容，已包含：
  - 日记原文
  - 已标注的情绪、状态评分
  - 大类标签、涉及人员
- **附加**：把当前已填写的卡片答案一并拼入初始消息（见下方）
- AI 会话为单一全局会话，在深度复盘期间唤起多次，共享同一个 localStorage key
- 关闭 AI 对话 → 回到卡片页面继续填写

### AI 初始消息扩展

在 `getInitialUserMessage` 基础上，从 ReflectionPage 传入已填的卡片内容：

```
【我在深度复盘时写下的】
当下念头：有点后悔答应这件事
核心需求：（未填）
（这些是我刚才自己整理的想法，你可以以此为起点）
```

## 保存逻辑

| 时机 | 行为 |
|---|---|
| 输入框失去焦点（onBlur） | fire-and-forget UPDATE 对应字段 |
| 点「关闭」 | fire-and-forget 保存当前输入框内容 → 导航回列表 |
| AI 对话完成 | 现有逻辑不变（full_conversation + 后台提取） |

**无"保存按钮"**，退出即完成，用户不需要做任何额外操作。

## 不在本次范围

- 认知扭曲（`cognitive_distortion_type`）相关问题：逻辑复杂，留给 AI 对话处理
- 问题卡片数量的个性化设置（当前固定 4 张）
- 情绪标注页 UI 的其他改动
- 离线保存

## 成功标准

1. 情绪标注页底部出现「深度复盘」和「完成」两个按钮，布局左小右大
2. 点「完成」行为与现在完全一致
3. 点「深度复盘」进入 ReflectionPage，能左右滑动切换 4 张卡片
4. 每张卡片的「↻ 换一个问题」能随机换一个同字段的不同问题
5. 输入内容 onBlur 后正确写入 Supabase 对应字段
6. 点「关闭」直接回列表，数据不丢失
7. 右下角 ✦ 按钮能唤起 AI 对话，AI 能看到日记内容 + 情绪标签 + 已填卡片内容
8. `npm run build` 零报错
