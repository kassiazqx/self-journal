# 感恩进度点设计

**日期：** 2026-04-21
**状态：** ✅ 设计确认

---

## 一、目标

在首页选中【感恩】模板时，引导词下方显示三个进度点（○○○），实时反映用户今天已保存的感恩条目数，激励每日写满 3 条。

---

## 二、位置

引导词行（彩色细竖线 + 引导文字）正下方，左对齐引导文字（跳过竖线宽度）。
仅当 `template.id === 'gratitude'` 时显示，其他模板不展示。

```
今天 3 件值得感恩的事 → 为什么 → 谁让我感到温暖
●○○
```

---

## 三、计数逻辑

- 查询 `journal_entries`，条件：`user_id = 当前用户` + `template_type = 'gratitude'` + `created_at >= 今日 00:00:00`
- 计数结果即为填充点数，最多填满 3 个（count ≥ 3 时显示 ●●●）
- 第 4 条、第 5 条仍可正常保存，点不再变化
- 每次保存成功后重新查询，点实时更新

---

## 四、样式

- 字符：`●`（实心）/ `○`（空心）
- 颜色：`#c9a96e`（感恩模板金色，与引导词一致）
- 字号：13px，字母间距 4px
- 左内边距：对齐引导文字（引导词区 padding-left 18px + 竖线 1.5px + gap 8px ≈ 27px）

---

## 五、数据

- **不新增 DB 字段**，纯前端查询
- `template_type = 'gratitude'` 已由现有保存逻辑写入，无需改动
- 查询函数放在 `src/lib/journalService.js`，不在页面直接访问 DB

---

## 六、成功标准

1. 选中【感恩】标签，看到 ○○○ 显示在引导词下方
2. 选其他模板，进度点消失
3. 保存一条感恩日记后，自动变 ●○○
4. 当日已有 3 条，进入页面直接显示 ●●●
5. 写第 4 条，点保持 ●●●，条目正常保存
